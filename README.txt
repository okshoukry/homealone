ROOM WORD HUNT

Files:
- room_word_game.html
- words.txt
- room.mp4 (use your existing room video and keep this exact filename)

Run through a local web server so the browser can load words.txt:

Python 3:
  python -m http.server 8000

Then open:
  http://localhost:8000/room_word_game.html

Controls:
- Drag left/right to look around.
- Tap letters in the correct order.
- Press Backspace to undo the last selected letter.

Edit words.txt to change the word list. Use one word per line.
